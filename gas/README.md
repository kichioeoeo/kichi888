# 線上訂單串接 Google 試算表（Google Apps Script）

網站結帳送出的訂單會寫進你的 Google 試算表，並自動寄 Email 通知店家與顧客。

```
顧客按「確認送出訂單」
        │  POST（JSON）
        ▼
Google Apps Script 網頁應用程式（gas/Code.gs）
  ├─ 用「菜單」工作表的價格重新計算金額（防止竄改）
  ├─ 產生訂單編號 JJ261127-001（每日流水號）
  ├─ 寫入「訂單」「訂單明細」工作表
  └─ 寄信：店家新訂單通知、顧客訂購確認信
        │
        ▼
網頁顯示訂單完成（編號與金額以 GAS 回傳為準）
```

## 一、建立試算表與程式（約 10 分鐘）

1. 到 [Google 試算表](https://sheets.google.com) 新增一份空白試算表，命名為「餃浸腦汁 訂單」。
2. 上方選單「**擴充功能 → Apps Script**」。
3. 把編輯器裡原本的內容全部刪掉，貼上本資料夾的 `Code.gs` 全文，按「儲存」。
4. 修改最上方的 `CONFIG`：
   - `NOTIFY_EMAIL`：店家收新訂單通知的信箱（留空＝試算表擁有者的信箱）
   - 其他（運費、免運門檻、訂單編號開頭）視需要調整，**需與網站設定一致**
5. 上方函式選單選 **`setup`** → 按「執行」。第一次會要求授權：
   選帳號 →「進階」→「前往（不安全）」→「允許」。
   （這是你自己寫的程式，Google 對未審核的個人腳本都會這樣提示。）
6. 回到試算表，會看到「訂單」「訂單明細」「菜單」三個工作表。
7. 函式選單選 **`installTriggers`** → 執行，啟用：
   - 狀態改成「可取餐／已出貨」時自動寄信通知顧客
   - 每天 21:30 寄營業摘要給店家

## 二、部署成網頁應用程式

1. Apps Script 右上角「**部署 → 新增部署作業**」。
2. 齒輪選「**網頁應用程式**」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
3. 按「部署」，複製「網頁應用程式網址」（`https://script.google.com/macros/s/……/exec`）。
4. 打開網址，看到 `{"ok":true,...}` 代表成功。

## 三、把網址填到網站

打開 `index.html`，找到：

```js
const ORDER_API = '';
```

把網址貼進引號內，存檔並上傳（或把網址傳給 Claude 代為修改）。
**未填網址時網站是「示範模式」**：訂單只顯示在畫面上，並標示「示範模式」，不會送到店家。

## 日常使用

| 工作表 | 用途 |
|---|---|
| 訂單 | 一筆訂單一列。「狀態」欄可下拉選：新訂單 → 製作中 → 可取餐／已出貨 → 已完成（或已取消），顏色會跟著變 |
| 訂單明細 | 每個品項一列，方便用樞紐分析表統計銷量 |
| 菜單 | 價格以這裡為準。改價格直接改這裡；取消勾選「上架」即暫停供應（顧客送出時會被提醒） |

- 「金額相符」欄出現「✗ 請確認」：代表顧客網頁上看到的金額和試算表菜單計算的不同（通常是你改了試算表價格但網站還沒同步），**以試算表的「總計」為準**。
- 修改試算表的菜單價格後，記得也請 Claude 同步修改網站上顯示的價格。

## 修改程式後重新部署（網址不變）

「部署 → 管理部署作業」→ 編輯（鉛筆）→ 版本選「**新版本**」→ 部署。
**不要用「新增部署作業」**，那會產生新網址。

## 注意事項

- **個資**：試算表內含顧客姓名、手機、地址，請勿把試算表分享成「知道連結的人都能檢視」。
- **寄信額度**：一般 Gmail 帳號每天約可寄 100 封、Google Workspace 約 1,500 封。訂單量大時可把 `SEND_CUSTOMER_EMAIL` 改成 `false`。
- **付款**：目前「信用卡／LINE Pay」僅記錄顧客選擇的付款方式，不會實際扣款；若要線上收款需另外串接金流服務（綠界、藍新、LINE Pay 等）。
- **防護**：已內建價格重算、數量上限、下架檢查、機器人陷阱欄位、試算表公式注入防護與同時下單的鎖定。
